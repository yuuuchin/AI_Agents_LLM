AI Agents 是什麼？

AI Agent 是一個能自主完成任務並與外部系統互動的智能系統

◆ 重點探討

  • 以大型語言模型（LLM）為核心，負責推理與決策
  • 能自主執行工作流程，不需要逐步人工指令
  • 可呼叫外部工具（如 API、資料庫）完成任務
💡 實例思考

你在手機上說「今天台北天氣？」，AI Agent 直接呼叫天氣 API，回傳天氣資訊給你。

LLM 基本概念

大型語言模型是能理解並生成自然語言的機器學習模型

◆ 重點探討

  • LLM 是以大量文本資料訓練的模型，能理解並生成自然語言。
  • LLM 本身只是模型，若結合工具與指令就能成為代理（Agent），能自主完成多步驟任務。
  • 代理與非代理 LLM 的區別：代理能呼叫工具、修正行為；非代理只回應輸入。
💡 實例思考

像是你在手機上問天氣，LLM 會根據大量資料回答你。

AI Agent：自主完成任務的智慧代理

AI Agent 是以大型語言模型為核心，能自主決策、使用工具並完成工作流程的系統

◆ 重點探討

  • 自主執行：不需要人工逐步指令，代理根據任務目標自行決策並選擇工具
  • 工具使用：可呼叫 API、查詢資料庫、發送訊息等，並根據工作進度動態選擇合適工具
  • 工作流程：代理的工作流程是一連串步驟，直到達成目標或遇到失敗時停止並回傳控制權
💡 實例思考

你在手機上問「今天台北天氣？」，AI Agent 直接呼叫天氣 API，回傳天氣資訊，完成整個查詢流程。

Agent 核心架構：工具（Tools）

工具讓 Agent 能呼叫外部功能完成任務

◆ 重點探討

  • 工具是 Agent 可呼叫的外部功能或 API，讓它能取得資料或執行動作。
  • 透過工具，Agent 能在工作流程中取得即時資訊或完成具體操作。
  • 工具在多步任務中扮演關鍵角色，支援 Agent 進行資料查詢、行動執行與網路搜尋。
💡 實例思考

旅遊訂票：Agent 先使用 Web Search 找航班資訊，接著呼叫 Flight API 訂票，最後使用 Hotel API 預訂住宿，完成整個旅遊行程。

Agent 工作流程概覽

Agent 透過 LLM、工具與指令，循環決策完成任務

◆ 重點探討

  • 接收輸入：Agent 先取得使用者訊息或外部事件。
  • LLM 產生決策：根據指令與防護規則，LLM 決定下一步行動。
  • 工具呼叫與迴圈：若決策為呼叫工具，Agent 執行並將結果回傳給 LLM，重複此流程直到達成結束條件。
💡 實例思考

旅遊訂票：使用者說「我要去東京，三月中旬的機票」，Agent 先搜尋航班、查詢價格，若符合預算則呼叫 Flight API 進行訂票，最後回覆訂票成功訊息。

Memory 記憶機制

記憶是模型保持對話連貫性的關鍵

◆ 重點探討

  • Memory（記憶）是模型在對話或任務過程中保存先前輸入、輸出或外部資訊的機制。
  • 記憶可分為短期記憶（對話歷史）與長期記憶（外部知識或先前學習的資訊）。
  • 透過記憶，模型能在後續對話中回憶並使用先前的資訊，維持上下文連貫性。
💡 實例思考

就像你在課堂上做筆記，當老師問你之前講過的內容時，你可以快速回想並回答。

RAG：結合檢索與生成的智慧回答

先找資料，再生成答案

◆ 重點探討

  • RAG 先從外部知識庫檢索相關片段
  • 將檢索結果與原始輸入拼接成新的上下文
  • LLM 在融合後的上下文中生成更準確、更具時效性的答案
💡 實例思考

智能客服在客戶詢問「如何重設密碼？」時，先檢索公司手冊中的「重設流程」段落，再結合對話歷史生成具體步驟

AI Agent：Agentic System

LLM 主動決策，靈活選擇工具完成任務

◆ 重點探討

  • Agentic System 讓 LLM 自主決定工作流程
  • LLM 可根據情況選擇不同工具（API、資料庫等）
  • 若發生失敗，Agent 會立即停止並交回控制權
💡 實例思考

旅遊助手：使用者想預訂餐廳，Agent 先搜尋空位，再預約並發送確認訊息，整個過程由 LLM 主動決策

限制、風險與安全

Guardrails 保障 Agent 行為可控

◆ 重點探討

  • Guardrails 是明確的安全規則，限制 Agent 的行為範圍，避免不當操作。
  • 透過 Guardrails，Agent 能在失敗時立即停止並將控制權交回使用者，確保安全。
  • 設置 Guardrails 是 Agent 設計中最重要的安全措施，能降低風險並維持倫理標準。
💡 實例思考

在餐廳預訂時，Agent 只會查詢空位；若無空位，Guardrails 會阻止預訂並告知使用者，避免預訂已滿座位。
